# PowerShell

Reusable PowerShell scripts and modules grouped by platform or workflow.

## Folders

- [active-directory](./active-directory) - AD helper functions.
- [app-pkg](./app-pkg) - legacy/internal app packaging automation.
- [azure](./azure) - Entra ID / Microsoft Graph scripts.
- [docker](./docker) - Docker helper functions.
- [hyper-v](./hyper-v) - Hyper-V utilities.
- [kubernetes](./kubernetes) - Kubernetes troubleshooting tools.
- [stig-etl](./stig-etl) - STIG data extraction/import tooling for ATO-Matic.

# Azure / Entra Automation

PowerShell automation for Azure, Entra ID, and Microsoft Graph workflows.

## Az-Preload-External-MFA.ps1

Script built around a migration scenario where external authentication methods needed to be preloaded for users through Microsoft Graph.

Use cases:

- prepare users for an external MFA migration
- automate Graph-based identity updates
- reduce repetitive manual Entra admin work

Review tenant permissions, Graph scopes, and input data before running in any real environment.
